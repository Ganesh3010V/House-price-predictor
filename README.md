# House Price Predictor 🏠

An end-to-end machine learning web application that predicts Bangalore house prices using a **Random Forest Regressor** wrapped in a scikit-learn Pipeline, served by **Flask**, with a modern dark-themed single-page frontend.

---

## Features

- 🤖 **ML Model** — RandomForest (200 trees) trained on 5 000 synthetic Bangalore property records
- 🔧 **Full Pipeline** — scikit-learn ColumnTransformer + OneHotEncoder + RandomForestRegressor, saved as a single `.pkl`
- ⚡ **REST API** — Flask `/predict` endpoint with thorough validation and clear error messages
- 🎨 **Modern UI** — Responsive card layout, animated price reveal, pool toggle, loading state
- 📊 **Report Assets** — Feature importance chart, actual vs predicted scatter, metrics text, sample predictions
- ✅ **End-to-end tested** — `test_api.py` verifies 3 properties and ordering sanity

## Setup

### 1. Create a virtual environment (optional but recommended)

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

---

## How to Run

### Step 1 — Generate synthetic data (if `data/house_data.csv` does not exist)

```bash
python generate_data.py
```

### Step 2 — Train the model

```bash
python train_model.py
```

Outputs:
- `model/house_model.pkl`
- `report_assets/metrics.txt`
- `report_assets/feature_importance.png`
- `report_assets/actual_vs_predicted.png`

### Step 3 — Start the Flask app

```bash
python app.py
```

Open **http://127.0.0.1:5000** in your browser.

### Step 4 — Run API tests (while Flask is running in a separate terminal)

```bash
python test_api.py
```

## Dataset Column Mapping

No external CSV was provided; the synthetic dataset was generated by `generate_data.py` using these exact column names:

| Column        | Type        | Range / Categories                                           |
|---------------|-------------|--------------------------------------------------------------|
| Area_SqFt     | int         | 400 – 5 000                                                  |
| Rooms         | int         | 1 – 10                                                       |
| Build_Year    | int         | 1990 – 2025                                                  |
| Location      | categorical | Indiranagar, Koramangala, Whitefield, HSR Layout, Jayanagar, Electronic City, Yelahanka, Marathahalli |
| Street_Type   | categorical | Main Road, Cross Road, Inner Lane, Highway Facing            |
| Furnishing    | categorical | Unfurnished, Semi-Furnished, Fully Furnished                 |
| Property_Type | categorical | Apartment, Independent House, Villa, Penthouse               |
| Has_Pool      | bool→int    | True/False → 1/0                                             |
| Price         | float       | Target in INR Lakhs                                          |
